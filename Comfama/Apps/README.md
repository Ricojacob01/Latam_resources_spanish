# Comfama — Sesión Express: Databricks Apps

**Duración:** 1 hora · **Tipo:** Tour interactivo · **Audiencia:** Equipo IA / Plataforma Comfama

Introducción **surface-level** a Databricks Apps. El workshop deep-dive hands-on viene a fin de mes (unified — Apps + Agents + Lakebase).

---

## Objetivo de esta hora

> Entender qué resuelve Databricks Apps, ver uno en acción, y dejar las preguntas listas para el workshop.

## Por qué importa para Comfama

Hoy ustedes hospedan el frontend del agente en **Azure Container Apps** (parte del Framework custom). Databricks Apps reemplaza esa pieza completamente — con auth integrada, serverless, integrado con su Unity Catalog, y sin gestión de containers.
